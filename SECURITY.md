# Security policy

Please report security problems privately to Microads Technology Company Limited through <https://microads.vn> (contact form or the phone
number on the site) or with a GitHub *private vulnerability report* on this repository — not in public issues.

Supported version: the latest release on <https://microads.vn/office/>. Updates are installed by the apps automatically (or with
*Check for updates*) and are verified with the Microads ECDSA release signature before installation.
